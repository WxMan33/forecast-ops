About these maps

NOAA HRRR, 3 km, shown on its own Lambert conformal grid: each coloured square is one model grid cell, not interpolated. Temperature is the 2-m value at the valid time. Simulated radar is the model's composite reflectivity (dBZ), not observed radar. Precipitation windows are read from the GRIB accumulation intervals: one-hour amounts are the model's own (N−1)–N h fields; 6- and 24-hour totals add consecutive one-hour fields from this run and are blank unless every hour is present; "since the run started" is the model's own 0–N h field. Missing hours are left blank, never shown as zero. County and state lines: US Census cartographic boundaries (us-atlas). Model guidance only, not an official forecast.
